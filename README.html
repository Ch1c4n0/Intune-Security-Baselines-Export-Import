🛡️ O que são Security Baselines no Intune?

As Security Baselines (Linhas de Base de Segurança) do Microsoft Intune são conjuntos pré-configurados de definições de segurança recomendadas pela Microsoft para dispositivos Windows. Elas agrupam centenas de configurações em um único perfil, baseadas nas melhores práticas da equipe de segurança da Microsoft, do CIS (Center for Internet Security) e do NIST.

"Security baselines are pre-configured groups of Windows settings that help you apply and enforce granular security settings that the relevant security teams recommend. You can also customize each baseline you deploy to enforce only those settings and values you require."
— Microsoft Learn, Security baselines in Intune

Por que é tão importante configurar?

MotivoImpacto
🔒 Redução de superfície de ataqueDesativa funcionalidades desnecessárias e exploráveis
🏛️ Conformidade regulatóriaAuxilia no atendimento a LGPD, ISO 27001, NIST, CIS
⚡ Velocidade de implantaçãoUma baseline substitui centenas de GPOs manuais
🧩 PadronizaçãoTodos os dispositivos seguem o mesmo padrão de segurança
🔁 Atualizações da MicrosoftCada versão do Windows recebe uma baseline atualizada
🛡️ Proteção contra ameaçasHabilita Defender, Firewall, restringe scripts e protocolos inseguros

O que as baselines cobrem?

  • Microsoft Defender Antivirus — proteção em tempo real, varredura, quarentena
  • Firewall do Windows — regras para redes de domínio, privadas e públicas
  • BitLocker — criptografia de disco completo
  • Windows Hello — autenticação sem senha e biometria
  • Auditoria e logs — rastreamento de eventos de logon e alterações de conta
  • Microsoft Edge — hardening de navegador
  • Credenciais e senhas — complexidade, expiração, bloqueio de conta
  • Controle de Conta de Usuário (UAC) — elevação de privilégios
  • Windows Update — políticas de atualização automática
💡 A Microsoft recomenda começar com as Security Baselines e depois ajustar conforme as necessidades da organização — em vez de criar políticas do zero.

📋 Visão Geral dos Scripts

PowerShell 7+ Sem Graph SDK Device Code / ROPC

Este projeto contém dois scripts PowerShell para exportar e importar Security Baselines do Microsoft Intune via Microsoft Graph REST API — sem necessidade do módulo Microsoft.Graph SDK.

Os scripts usam autenticação delegada (Device Code ou usuário/senha), ideal para ambientes onde o módulo SDK causa conflitos de versão de assembly MSAL.

💡 Os JSONs exportados são compatíveis com o formato do repositório dgulle/Security-Baselines.

⚙️ Pré-requisitos

  • PowerShell 7 ou superior
  • Acesso ao Microsoft Entra ID (Azure AD) para registrar um aplicativo
  • Conta com permissão DeviceManagementConfiguration.ReadWrite.All no tenant

🔐 Registro do Aplicativo no Entra ID

É necessário registrar um aplicativo próprio no Entra ID para obter um clientId e tenantId que serão configurados nos scripts.

⚠️ Não use o clientId genérico do Microsoft Graph Command Line Tools — políticas de Conditional Access do tenant podem bloqueá-lo em dispositivos não gerenciados.
1

Criar o registro

Acesse Entra ID → App registrations → New registration.
Nome: Intune Baselines Script | Tipo de conta: Single tenant | Redirect URI: deixar em branco.

2

Habilitar Public Client (Device Code)

Authentication → Add a platform → Mobile and desktop applications.
Marque https://login.microsoftonline.com/common/oauth2/nativeclient.
Em Advanced settings: Allow public client flows → Yes. Salve.

3

Adicionar permissão delegada

API permissions → Add a permission → Microsoft Graph → Delegated permissions:

PermissãoTipoMotivo
DeviceManagementConfiguration.ReadWrite.AllDelegatedLer e criar políticas no Intune

Clique em Grant admin consent e confirme.

4

Copiar os IDs

Em Overview do app registrado, copie:
• Application (client) ID → será o $clientId
• Directory (tenant) ID → será o $tenantId

5

Configurar nos scripts

Abra Export-SecurityBaselines.ps1 e Import-SecurityBaselines.ps1 e substitua os placeholders:

$clientId = "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"   # Application (client) ID
$tenantId = "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"   # Directory (tenant) ID

Export-SecurityBaselines.ps1

Exporta Security Baseline templates do Intune para JSON

O que faz

  • Lista todos os Security Baseline templates disponíveis no tenant (incluindo os sem perfil criado)
  • Apresenta seleção interativa (Out-GridView) para escolher quais exportar
  • Cria um perfil temporário para capturar os valores padrão recomendados pela Microsoft
  • Salva um JSON completo da baseline e JSONs individuais organizados por categoria (Defender, Auditing, Browser, Firewall, etc.)
  • Remove o perfil temporário automaticamente ao final

Estrutura de pastas gerada

Exported-Baselines\
  Security Baseline for Windows 10 and later - Version 25H2\
    Security Baseline for Windows 10 and later - Version 25H2.json  ← baseline completa
    Defender\
      001 - Allow Archive Scanning\
      002 - Allow Behavior Monitoring\
    Auditing\
      001 - Audit Account Logon\
    Firewall\
      001 - Enable Domain Network\
      ...

Como usar

# Exportar para pasta padrão (.\Exported-Baselines\<timestamp>)
.\Export-SecurityBaselines.ps1

# Exportar para pasta específica
.\Export-SecurityBaselines.ps1 -OutputPath "C:\Backup\Baselines"

# Informar UPN (pula digitação no login)
.\Export-SecurityBaselines.ps1 -AdminUPN "admin@contoso.com"

Parâmetros

ParâmetroPadrãoDescrição
-OutputPath.\Exported-Baselines\<timestamp>Pasta de destino dos JSONs
-AdminUPNvazioUPN do admin (hint de login)

Autenticação

Ao iniciar, o script pergunta o método de autenticação:

  • [1] Device code — abre o navegador com código (https://login.microsoft.com/device)
  • [2] Usuário e senha — digita diretamente no terminal (ROPC flow, requer conta sem MFA obrigatório)
⚠️ O fluxo usuário/senha (ROPC) não funciona com contas que têm MFA obrigatório. Nesse caso use o device code.
📥

Import-SecurityBaselines.ps1

Importa Security Baselines para o Intune a partir de JSONs exportados

O que faz

  • Busca recursivamente arquivos .json na pasta informada
  • Apresenta seleção interativa (Out-GridView) com colunas Categoria, Configuração, Template e Settings
  • Permite unir settings da mesma categoria em uma única política
  • Permite renomear cada política antes de importar
  • Verifica duplicatas e suporta sobrescrita com -OverwriteExisting
  • Suporta atribuição automática a grupo do Entra ID

Como usar

# Importar da pasta atual como Security Baseline (preserva templateReference)
.\Import-SecurityBaselines.ps1 -KeepAsBaseline

# Importar como Settings Catalog (sem vínculo ao template)
.\Import-SecurityBaselines.ps1

# Importar de pasta específica e atribuir a grupo
.\Import-SecurityBaselines.ps1 -SourcePath "C:\Baselines" `
    -GroupAssignmentId "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx" -KeepAsBaseline

# Sobrescrever políticas existentes com o mesmo nome
.\Import-SecurityBaselines.ps1 -KeepAsBaseline -OverwriteExisting

Parâmetros

ParâmetroPadrãoDescrição
-SourcePathPasta atualPasta com os arquivos JSON (busca recursiva)
-GroupAssignmentIdvazioObject ID de grupo para atribuição automática
-AdminUPNvazioUPN do admin (hint de login)
-KeepAsBaselinenãoPreserva o vínculo com o Security Baseline template
-OverwriteExistingnãoDeleta e recria políticas com nome idêntico
✅ Dica: Use -KeepAsBaseline para que as políticas apareçam em Endpoint Security → Security Baselines. Sem esse switch, aparecem em Devices → Configuration.

📄 Logs e Debug

Os arquivos de log são salvos na mesma pasta do script:

  • Export-SecurityBaselines.log — log de execução da exportação
  • Import-SecurityBaselines.log — log de execução da importação
  • DEBUG_settingTemplates_*.json — raw dos templates da API (removível após uso)
  • DEBUG_converted_*.json — settings convertidas antes do POST (removível após uso)

🛡️ What are Security Baselines in Intune?

Security Baselines in Microsoft Intune are pre-configured groups of Windows security settings recommended by Microsoft. They bundle hundreds of security configurations into a single profile, based on best practices from Microsoft's security team, the CIS (Center for Internet Security), and NIST (National Institute of Standards and Technology).

"Security baselines are pre-configured groups of Windows settings that help you apply and enforce granular security settings that the relevant security teams recommend. You can also customize each baseline you deploy to enforce only those settings and values you require."
— Microsoft Learn, Security baselines in Intune

Why is it so important to configure?

ReasonImpact
🔒 Attack surface reductionDisables unnecessary and potentially exploitable features
🏛️ Regulatory complianceHelps meet ISO 27001, NIST, CIS Benchmarks requirements
⚡ Deployment speedOne baseline replaces hundreds of manual GPO configurations
🧩 StandardizationAll devices follow the same minimum security standard
🔁 Microsoft updatesEach new Windows version gets an updated baseline with latest protections
🛡️ Threat protectionEnables Defender, Firewall, restricts scripts and insecure protocols

What do Security Baselines cover?

  • Microsoft Defender Antivirus — real-time protection, scanning, quarantine
  • Windows Firewall — rules for domain, private, and public networks
  • BitLocker — full disk encryption
  • Windows Hello — passwordless authentication and biometrics
  • Auditing and logs — tracking logon events and account changes
  • Microsoft Edge — browser hardening
  • Credentials and passwords — complexity, expiration, account lockout
  • User Account Control (UAC) — privilege elevation
  • Windows Update — automatic update policies
💡 Microsoft recommends starting with Security Baselines and then adjusting to your organization's specific needs — rather than building policies from scratch.

Export-SecurityBaselines.ps1

Exports Intune Security Baseline templates to JSON files

What it does

  • Lists all Security Baseline templates available in the tenant (including those without any profile created)
  • Shows an interactive selection dialog (Out-GridView) to choose which templates to export
  • Creates a temporary profile to capture Microsoft's recommended default values
  • Saves a full JSON of the baseline and individual JSONs organized by category (Defender, Auditing, Browser, Firewall, etc.)
  • Automatically removes the temporary profile when done

Generated folder structure

Exported-Baselines\
  Security Baseline for Windows 10 and later - Version 25H2\
    Security Baseline for Windows 10 and later - Version 25H2.json  ← full baseline
    Defender\
      001 - Allow Archive Scanning\
      002 - Allow Behavior Monitoring\
    Auditing\
      001 - Audit Account Logon\
    Firewall\
      001 - Enable Domain Network\
      ...

How to use

# Export to default folder (.\Exported-Baselines\<timestamp>)
.\Export-SecurityBaselines.ps1

# Export to a specific folder
.\Export-SecurityBaselines.ps1 -OutputPath "C:\Backup\Baselines"

# Provide UPN (skips typing during login)
.\Export-SecurityBaselines.ps1 -AdminUPN "admin@contoso.com"

Parameters

ParameterDefaultDescription
-OutputPath.\Exported-Baselines\<timestamp>Destination folder for JSON files
-AdminUPNemptyAdmin UPN (login hint)

Authentication

When the script starts, it prompts for the authentication method:

  • [1] Device code — opens browser with a code (https://login.microsoft.com/device)
  • [2] Username and password — type credentials directly in the terminal (ROPC flow, requires account without mandatory MFA)
⚠️ The username/password flow (ROPC) does not work with accounts that have mandatory MFA. In that case, use device code.
📥

Import-SecurityBaselines.ps1

Imports Security Baselines into Intune from exported JSON files

What it does

  • Recursively searches for .json files in the specified folder
  • Shows an interactive selection dialog (Out-GridView) with Category, Configuration, Template, and Settings columns
  • Allows merging settings from the same category into a single policy
  • Allows renaming each policy before importing
  • Checks for duplicates and supports overwriting with -OverwriteExisting
  • Supports automatic assignment to an Entra ID group

How to use

# Import from current folder as Security Baseline (preserves templateReference)
.\Import-SecurityBaselines.ps1 -KeepAsBaseline

# Import as Settings Catalog (no template link)
.\Import-SecurityBaselines.ps1

# Import from specific folder and assign to a group
.\Import-SecurityBaselines.ps1 -SourcePath "C:\Baselines" `
    -GroupAssignmentId "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx" -KeepAsBaseline

# Overwrite existing policies with the same name
.\Import-SecurityBaselines.ps1 -KeepAsBaseline -OverwriteExisting

Parameters

ParameterDefaultDescription
-SourcePathCurrent folderFolder with JSON files (recursive search)
-GroupAssignmentIdemptyGroup Object ID for automatic assignment
-AdminUPNemptyAdmin UPN (login hint)
-KeepAsBaselinenoPreserves the link to the Security Baseline template
-OverwriteExistingnoDeletes and recreates policies with the same name
✅ Tip: Use -KeepAsBaseline so policies appear under Endpoint Security → Security Baselines. Without this switch, they appear under Devices → Configuration.

📄 Logs and Debug Files

Log files are saved in the same folder as the script:

  • Export-SecurityBaselines.log — export execution log
  • Import-SecurityBaselines.log — import execution log
  • DEBUG_settingTemplates_*.json — raw API template data (can be deleted after use)
  • DEBUG_converted_*.json — converted settings before POST (can be deleted after use)
